# BuildPlugin (Paper 26.3)

Система будівництва як у Rust. Збірка: GitHub → Actions → Build → Artifacts → `BuildPlugin.jar`.

## Як користуватись
1. **Крафт плану:** одне дерево (дошки або колода) рівно у 5-му слоті (центр) верстака 3x3 → «План будівництва» (карта).
2. З планом у руці: **ЛКМ** — змінити частину (Фундамент → Стіна → Підлога → Дверний проєм), **ПКМ по блоку** — побудувати.
3. Усе будується з дерева, потрібні дошки в інвентарі. Якщо матеріалів бракує — плагін напише, скільки треба.
4. **/upgrade** (дивлячись на частину) — дерево → камінь → залізо → обсидіан. Вартість беруться за новий рівень.
5. **/demolish** — знищити частину (повертається частина матеріалів).
6. **/plan** (тільки адмін) — видати план без крафту.

## Правила розміщення (сітка 3x3)
- **Фундамент** 3x1x3: клікни по землі. Щоб розширити — клікни збоку існуючого фундаменту.
- **Стіна** 3x3x1 і **Дверний проєм** (стіна з отвором 1x2): клікни по верху фундаменту/підлоги біля потрібного краю.
- **Підлога** 3x1x3: клікни по верху стіни (один поверх = 1 підлога + 3 висоти стіни) або збоку іншої підлоги.

## Вартість і налаштування
`plugins/BuildPlugin/config.yml`: вартість кожної частини на кожному рівні, `creative-free`, `owner-only`, `refund-percent`.
Блоки споруд не ламаються руками, вибухами, вогнем чи поршнями — тільки /demolish.
Дані зберігаються в `plugins/BuildPlugin/pieces.yml`.
